# Quy trình đưa skill/template vào kit
1. Tạo branch + PR vào `sf-delivery-kit`, mô tả: bài toán, dự án đã dùng thử.
2. Owner (theo CODEOWNERS) review: tính tổng quát, không chứa dữ liệu khách hàng/credential.
3. Cập nhật `skill-catalog.md` và `CHANGELOG.md`, tăng version (semver).
4. Merge + gắn tag.
