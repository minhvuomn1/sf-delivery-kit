# BRD (Business Requirements Document)
Bỏ BRD gốc của khách vào đây (md/pdf/docx). Đặt tên `BRD-vX.Y-<ten>.<ext>`; bản mới không ghi đè bản cũ.
Agent đọc thư mục này (cùng `fsd/`) khi chạy `/setup-skills` và `/journey`.
Rút gọn nội dung vào `../business-rules.md` (BR-xx) và `../journeys/`; không sao chép nguyên văn.
