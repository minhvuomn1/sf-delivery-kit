# FSD (Functional Specification)
Bỏ FSD vào đây, đặt tên `FSD-vX.Y-<module>.<ext>`. Ưu tiên md hoặc pdf (agent đọc trực tiếp); docx nên xuất ra pdf/md trước.
Dùng sub-agent `fsd-analyst` để liệt kê object/field/BR/màn hình và câu hỏi còn mở.
Nếu FSD nằm trong NotebookLM: không cần copy file, xem `.claude/skills/project-skill-sync`.
