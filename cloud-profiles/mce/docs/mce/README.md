# Marketing Cloud Engagement (MCE)
MCE là hệ thống riêng, KHÔNG nằm trong org Salesforce core: metadata không deploy bằng `sf project deploy`. Vì vậy tài liệu ở đây là nguồn truy vết chính.

| File | Nội dung |
|------|----------|
| `business-units.md` | Business Unit, Parent/Child, quyền, sender profile, send classification |
| `data-extensions.md` | Danh mục Data Extension: PK, retention, sendable, nguồn dữ liệu |
| `journeys.md` | Journey Builder: entry source, split, wait, exit, goal |
| `automations.md` | Automation Studio: lịch, activity, thứ tự, người sở hữu |
| `mc-connect.md` | Marketing Cloud Connect / Synchronized Data Sources / Salesforce Data |
| `queries/` | SQL query activity (mỗi file một query, ghi DE đích + mode Overwrite/Append/Update) |
| `templates/` | Email/CloudPage template, AMPscript block |
